# HR_Attrition
. Strategic Problem StatementThe project was defined by the "Burnout Threshold" hypothesis. Instead of looking purely at financial reasons for turnover, we investigated how the intersection of WorkHours (workload) and JobSatisfaction (wellbeing) predicts an employee’s decision to leave. The goal was to provide HR with a proactive tool to trigger interventions—such as specialized training or workload redistribution—before a resignation occurs.2. Data Lifecycle (Steps 2 - 4)Collection: Utilized a dataset of 500 records featuring metrics such as Age, Salary, Experience, Department, WorkHours, and JobSatisfaction.Cleaning: Audited data for integrity. No missing values or duplicates were found, ensuring a clean baseline for the model.EDA (Exploratory Data Analysis): Visualized the "Burnout" signals. We discovered that high workload density often overrides salary levels in predicting attrition for certain employee segments.3. Model Engineering (Steps 5 - 6)We moved beyond simple observations to mathematical prediction:The Algorithm: We selected the Random Forest Classifier. This model was chosen because it provides Feature Importance, allowing us to rank exactly which factors (e.g., WorkHours vs. Salary) drive attrition most heavily.Preparation: Applied StandardScaler to ensure that features with different scales (like Salary in thousands vs. WorkHours in single digits) were treated with equal importance by the algorithm.Performance: The model was evaluated using a Confusion Matrix to ensure we were successfully catching "At-Risk" employees (Recall) without excessive false alarms (Precision).4. Operational Deployment (Step 7)To make the model useful for daily HR operations, we created:Persistence: Saved the model and scaler as .pkl files for instant reuse.Risk Calculator: A Python-based tool that takes an individual employee's profile and returns a Risk Probability Score.Action Plan: High-risk scores (>60%) are now linked to specific HR actions, such as mandatory wellbeing checks or enrollment in leadership development programs.Final Project Deliverables (The 5-File Toolkit)File TypePurposeNotebook (.ipynb)The complete "source code" and experimental steps in Google Colab.Model & Scaler (.pkl)The "saved brain" of the model and the pre-processing tool.Data (.csv)The original dataset used to train the system.Report (.pdf)The corporate-ready presentation summarizing findings for stakeholders.DocumentationThe README guide explaining how to run and maintain the project.Summary Conclusion:By integrating data science into HR training and development, we have transitioned from subjective "gut feelings" about employee morale to a predictive, data-backed retention strategy.
